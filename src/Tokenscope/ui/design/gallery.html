Design system

Every token and component Tokenscope is built from, live. Each snippet is generated from the example above it, so it cannot drift. Rules: tokens only, animate only transform / opacity / filter, state lives in native attributes.

Motion

Three springs, each a duration + linear() pair: transition: translate var(--spring-snappy). Hover is instant or ≤ 120 ms, presses respond immediately, releases spring back.

Reduced motion

With “Show animations” off in Windows, every transition becomes a 120 ms opacity fade: no travel, no scale, no shimmer. Nothing to do per component — the block at the end of components.css handles it.
